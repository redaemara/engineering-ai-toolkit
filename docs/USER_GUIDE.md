# User guide

Open index.html, choose a module, enter numeric values and click Calculate. Unit conversion chooses dimension and compatible units. Material and section tools use mm for cross-section dimensions, m for length, kg/m³ for density. Only fields relevant to the selected geometry are used. Use custom area for arbitrary manufacturer profiles without copying proprietary data.

Cutting: supply one length,quantity pair per line. Confirm kerf per finished piece and per-end trim. Review purchased, product, saw/trim loss, remnant and utilization. Green is product, amber is loss, gray is remnant. All bars appear in the table and CSV; layout display caps at 100 bars.

Takeoff: enter item,type,L,W,H,count,rate per line. Types are linear,area,volume; use zero for unused dimensions and rates. Do not include commas in item names. The result shows independent item quantities and cost, not a sum of incompatible units. Export CSV using Download CSV.

Review input units and limitations. All results are estimates, not approved engineering designs.
